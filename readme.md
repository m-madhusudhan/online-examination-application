# Online Examination Application

A Java-based Online Examination Application designed to facilitate remote quizzes and assessments for educational institutions.  
It supports real-time scoring, automated grading, and comprehensive reporting to enhance the examination process.

---

## Features
- Real-Time Scoring: Instant feedback after each question.
- Automated Grading: Automatically evaluates answers and computes results.
- Comprehensive Reporting: Generates detailed text-based reports after each exam.
- User-Friendly Interface: Simple and intuitive console-based exam interface.
- Remote Assessment: Supports seamless online examination workflows.

---

## Technologies Used
- Language: Java (JDK 8 or higher)
- Core Concepts: Object-Oriented Programming (OOP), File I/O, Collections, Exception Handling
